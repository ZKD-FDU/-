# 洪策演示脚本

## 1. 启动

终端 A：

```bash
PYTHONPATH=src python3 -m api.simple_server
```

终端 B：

```bash
cd web
python3 -m http.server 5173 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:5173`。

## 2. 演示顺序

1. 县域态势总览：点击“运行仿真”，说明系统正在执行本地多智能体模型。
2. 情景编辑器：切换 S0、S3、S5，展示政策配置不是静态截图。
3. 实时推演：展示预警、通信降级、桥梁关闭、转运等事件流。
4. 叫应确认台：展示脆弱群体逐户状态和阻塞原因。
5. 政策对比：点击“运行 A/B/C 实验”，等待批量仿真完成后比较 S0-S5。
6. 个体与事件解释：展示个体决策轨迹。
7. 复盘与建议：说明建议来自当前仿真和批量实验。

## 3. 讲述重点

- 没有外部模型 Key 时系统完整可运行。
- 所有比较指标来自实时仿真输出。
- S5 通常在安全转移率和闭环率上优于 S0，但结论标注为 SIMULATED，不作为真实因果证明。
