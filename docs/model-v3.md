# 洪策 v3：模型依据、计算规则与适用范围

本轮实现是可复现的合成情景政策沙盘。它将信息传播、组织授权、人员决策和走廊级运输连接起来；尚不是经过历史洪水校准的水动力模型或现实指挥系统。前端建筑、等高线与补充备用道路为示意，不能据此判断真实地形、通行或安置安全。

## 设计依据与实际采用内容

检索日期：2026-09-06。以下为设计参考，未宣称与这些软件建立了集成。

## 计算与数据口径

1. **时间与随机性**：内核按分钟推进，到达、返程和基础设施失效在实际分钟生效；行为决策按 5/10/15 分钟更新。同一种子的人口和事件抽样由人员/事件键固定，策略改变不改变抽样流。每次运行深拷贝输入，记录情景哈希、政策哈希和内核版本。
2. **信息与组织**：家庭、邻里、线上关系有方向、延迟和失败；人工确认任务由有处理容量的村干部或机构工作人员完成。动态补登记、先行授权和机构准备时间改变真实流程。规则决策器输出信息依据、行为因素与随机抽样记录。未将 LLM、MDP 接口或候选动作比较称为已经训练完成的强化学习。
3. **运输**：人员先等待可用车辆、随车照护人员和担架，再装载出发。同车人员使用同一出发点、路线和安置点。车辆在往返完成前持续占用；无法完成返程时，本轮停留安置点，相关资源不再使用。模型假定各轮车辆已在需求点待命，不解析车库到需求点的空驶再定位。
4. **积水和路线**：`depth_profile` 使用 `[分钟, 水深米]` 线性插值。以行程窗口内的峰值水深 D，按 `T=ceil(T0 / max(0.25, 1-0.65*D/D_limit))` 迭代估计减速，直到稳定；达到关闭阈值、迭代不收敛或预计无法在封路前通过则不派车。该减速式及默认 0.30 m 阈值为工程假设，**不是车辆安全通行标准**，未纳入流速、车辆型号、冲刷和漂浮物。未来水深视为已知情景输入，尚未区分预报误差与真实灾害。
5. **容量**：走廊同时占用上限包括装载、往返和保守停留占用；不是每分钟车辆流量，也没有共享交叉口解析。总床位按安置点容量权重分配，所有安置点容量之和严格等于本轮总预算；出发前预留床位，全照护者同时占用专属接收名额。资源为零时不创造最低运力。
6. **排序与公平**：S0 按等待时间，优先型方案考虑脆弱性；超过等待提权阈值后按等待长度提权。这个阈值不是最长等待时间保证，资源极度不足仍可能无法覆盖普通人群。页面同时显示总体、脆弱与普通人群结果。
7. **指标**：按时安全转移率的分母为应转人群，分子为危险到达前实际安置者；两个人群使用各自应转人数。缺少任一组时差距不定义。人工确认与同意转移分开计算。关键动作目前限于按期触达、同意和出发三项。暴露指标按危险到达后到实际安置间累计，为合成风险指数，非伤亡概率；信任变化尚未校准，输出空值。

## 参数与空间输入

统一入口为 `configuration.normalize_scenario_config` 与 `build_scenario`，单次 API、CLI、批次和参数搜索共用。`transport_mode=network` 为应用默认；底层 `generate_qingyuan` 的无网络形式保留为兼容性测试夹具。

| 字段 | 默认 | 含义 / 来源 |
|---|---:|---|
| `road_capacity` | 8 | 单走廊保守并发车辆上限；合成假设 |
| `loading_minutes` | 5 | 每车装载时间；合成假设 |
| `queue_aging_minutes` | 45 | 等待提权阈值；非保证时限 |
| `flood_peak_m` | 0.45 | 默认低洼路线过程线峰值；合成假设 |
| `road_depth_limit_m` | 0.30 | 情景关闭阈值；不可作为现实涉水建议 |
| `routes` | 自动补齐 | 支持行程、安置点、桥依赖、关闭时刻、并发上限和完整过程线 |
| `shelters` | 两处合成安置点 | 支持床位权重与全照护接收名额；读取空间包中的安置点 |

前端加载清源空间包时会使用该包推导的输入；报告中的标准实验采用 `DEFAULT_SCENARIO_CONFIG`。两者参数不同，页面保留实际配置和版本，不能直接把单次沙盘结果当作标准 50 种子实验复现。

## 下一步现实校准所需数据

- DEM 与河网、实测水位/流量/淹没范围、桥涵高程、道路关闭记录，用来接入和校准 HEC-RAS 或其他水动力模型。
- 逐路段长度、限速、车道容量、备用道路可用性和车辆轨迹；把走廊级占用替换为共享道路网络与路口排队。
- 分人群接触/理解/确认/准备时间，机构授权记录及演练名册；校准规则分布，检验结构性偏差。
- 车辆类别、车库与司机排班、装载和空驶时间、照护人员班次、逐安置点接收与医护能力。
- 独立历史事件或演练作为留出集，报告到达时间误差、人数误差、覆盖率和置信区间覆盖，而非仅靠模拟种子判断现实可靠性。

当前应转规则仍按合成地点与脆弱属性定义，未由逐建筑水深动态生成；家庭整组转移、行人微观避障、私家车交通和长期安置需求尚未完成。缺少这些数据时，应把结果用于机制检查与压力测试，不用于真实灾害处置承诺。
