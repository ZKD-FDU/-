# v4 验证结果与三维界面验收

数据版本：`hongce-positioned-kernel-v4`。实验于 2026-09-11 完成，界面回退及最终代码复核于 2026-09-12 完成。

## 可复核的范围

同一组 50 个随机种子（202609110–202609159）共 **1,850 次**：150 次 S0/S3/S5 基线、1,100 次 A/B/C 机制实验、300 次压力测试、300 次车队对照。基线与车队对照人口为 2,000，机制及压力实验人口为 500。完整批次耗时 1738.39 秒。

本轮检查了 CSV 的唯一键、版本、种子、各方案 50 次重复，以及 185 项汇总均值；最终代码另重跑首个种子的六个车队方案，运行 ID、情景哈希、按时人数及三组安全率均与归档一致。这六次为复核，不计入 1,850 次归档。

证据：[汇总 JSON](../data/validation/competition_v4.json)、[逐次 CSV](../data/validation/competition_v4_runs.csv)、[复现脚本](../scripts/validate_competition.py)。CI95 为 400 次固定种子 bootstrap 的均值区间；它不是单次灾情范围，P05–P95 另保存在 JSON。种子重复只检验模型内稳定性，未进行实测灾情校准。

## 界面验收

后端 `python -m unittest discover -s tests -q` 共 73 项通过；包含车队位置连续、空驶封路、单向道路、双向共享容量、资源预约和兼容自定义安置点的检查。前端模块通过 Node 语法检查。

恢复初步修改版本的原样式和深蓝指挥舱，以真实 WebGL 三维画布展示合成地形及事件；移除本轮不被接受的 SVG 替代地图。保留原仪表盘与内核改进。

浏览器验证覆盖 1600×1100 桌面与 390×844 窄屏：单个有效 WebGL 画布、三维场景无加载错误、八个设施标签在全景下无重叠、缩放时标签保持固定宽度、图层改变实际渲染画面、拖动旋转、设施近景定位、车次分段与 API 一致、回放安置和车辆占用计数一致、参数修改标记待重跑、集结点及派车规则实际应用、离开/返回视图释放并恢复画布、窄屏无横向溢出。共 23 项交互断言通过，未发现浏览器异常或控制台警告。近景人工检查修复了学校设施穿入地形的问题。

这仍是合成地理研究沙盘：地形高程、建筑尺度、河流水位表现没有实测依据，路段积水色带不是二维水动力淹没结果；车流没有真实交叉口、跟驰与普通社会车辆。后续真实性提升需要真实地理、道路拓扑与演练数据，不以视觉细节替代校准。
