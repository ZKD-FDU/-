# 模型卡

## 模型类型

离线规则多智能体模型。默认适配器为 `RuleBasedAgentAdapter`。

## 决策因素

个体转移决策由风险感知、官方信任、干部信任、邻里行动、直接协助、提前量、转移成本、误报疲劳、路线障碍、拒绝倾向共同决定。

## 资源调度

车辆、照护人员、担架和避难床位按政策配置动态消耗。脆弱优先策略会提高脆弱个体派车和照护优先级。

## 可解释性

每次运行写出事件流、消息回执、个体状态和 `DecisionTrace`。`explain` 命令与 API 会生成代表性脆弱个体解释包。

## 限制

规则权重用于竞赛 MVP 和方法展示，尚未基于真实历史事件校准。外部大模型可通过适配器增强画像与话语解释，但不能替代状态机和调度约束。
